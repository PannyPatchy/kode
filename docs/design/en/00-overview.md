# 00. Overview

> Translation: [日本語](../ja/00-overview.md) ／ [Back to index](../README.md)

## 1. Concept

**`kode` — a Kotlin codebase comprehension CLI for AI agents.**

Instead of having an AI spam `grep` / `find`, `kode` gathers the information it needs from multiple sources (LSP, Gradle Tooling API, etc.) and **returns it as JSON in a single command**. Semantic interpretation is the AI's responsibility, not this tool's.

`kode`'s responsibility is strictly to **collect accurate data, structure it, and return JSON**. It does not decide what the correct fix is or which test to add.

## 2. Problems It Solves

- AIs spam `grep` / `find`, which is inefficient.
- AIs write their own Python (or other) scripts to muscle through.
- Information that could be returned by a single command is instead gathered by trial and error.

## 3. User Stories

| Scene | Where the AI gets stuck | What kode solves |
|-------|-------------------------|------------------|
| Bug fix | Can't grasp type info / impact around the error | Returns the error + surrounding snippet in one shot (`kode errors`) |
| Refactoring | Can't exhaustively grasp references / affected tests | Returns references (`kode refs`) and related tests (`kode test`) |
| New feature | Spams grep to understand existing structure | Returns tree structure / symbol list (`kode tree` / `kode symbols`) |
| Adding tests | Painful to find related tests | Returns related test classes / functions (`kode test`) |

## 4. Design Principles

- Output is **always JSON** (for AIs). No human-oriented decoration.
- **No semantic interpretation.** Responsibility ends at providing data.
- `kode --help` output doubles as the **manual for the AI** (Clikt's auto-generated help describes each command's JSON schema).
- Adopt **Clean Architecture / DDD** to isolate the domain from external tech (LSP/Gradle/FS) ([01](01-architecture.md) / [02](02-domain-model.md)).
- **OSS publication assumed.** Only permissive or non-propagating-copyleft dependencies ([09](09-dependencies-license.md)).

## 5. Command List

| Command | Summary | Primary source |
|---------|---------|----------------|
| `kode init` | Recognize project, generate `.kode.json` | Gradle Tooling API |
| `kode errors <file>` | Errors/warnings + surrounding snippets | LSP |
| `kode refs <class/function>` | List of references | LSP |
| `kode test <class/function>` | Related test classes/functions | Gradle Tooling API |
| `kode tree` | Whole-project file tree | FileSystem |
| `kode symbols <file>` | Classes/functions/properties | LSP |

See [03. Command Flows](03-commands.md) for each command's I/O schema and flow.

## 7. Project Recognition (`.kode.json`)

- Generated by `kode init`.
- Recommended to `.gitignore` (environment-dependent).
- Team sharing is not intended (personal dev environment only).

See [06. Config I/O](06-config-kode-json.md).

## 8. Out of Scope

- Languages other than Kotlin.
- Maven support (future).
- Team sharing / cloud integration.
- Semantic interpretation / judgement (the AI's responsibility).
- Coverage collection.
