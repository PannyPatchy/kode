# Security Policy / セキュリティポリシー

## Reporting a Vulnerability / 脆弱性の報告

**日本語:**  
セキュリティ上の脆弱性を発見された場合は、[GitHub Issues](https://github.com/PannyPatchy/kode/issues) にてご報告ください。  
報告の際は、再現手順・影響範囲・深刻度についてできる限り詳しく記載してください。  
報告を受け次第、内容を確認の上できる限り速やかに対応します。

**English:**  
If you discover a security vulnerability, please report it via [GitHub Issues](https://github.com/PannyPatchy/kode/issues).  
Please include as much detail as possible: steps to reproduce, potential impact, and severity assessment.  
We will review the report and respond as promptly as possible.

---

## Scope / 対象範囲

**日本語:**  
本ポリシーは `kode` CLI ツール本体に関する脆弱性を対象とします。  
サードパーティ依存ライブラリの脆弱性については、各ライブラリのセキュリティポリシーに従ってご報告ください。

**English:**  
This policy covers vulnerabilities in the `kode` CLI tool itself.  
For vulnerabilities in third-party dependencies, please follow the security policy of the respective library.
