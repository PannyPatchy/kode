# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it **privately** via GitHub's private vulnerability reporting:

**[Report a vulnerability](https://github.com/PannyPatchy/kode/security/advisories/new)**

Do **not** open a public issue for security vulnerabilities.

Please include as much detail as possible: steps to reproduce, potential impact, and a severity assessment. We will review the report and respond as promptly as possible.

日本語での報告も歓迎します。(Reports in Japanese are also welcome.)

## Scope

This policy covers vulnerabilities in the `kode` CLI tool itself. For vulnerabilities in third-party dependencies (including the JetBrains Kotlin LSP), please follow the security policy of the respective project.
