# kode

AIエージェントのためのKotlinコードベース理解CLI。
A Kotlin codebase comprehension CLI for AI agents.

📐 **設計書 / Design document**: [`docs/design/`](docs/design/README.md)

## Status

Initial scaffold. The `kode init` command is implemented end-to-end; the other
commands (`errors`, `refs`, `test`, `tree`, `symbols`) are subcommand stubs that
return a `NOT_IMPLEMENTED` error envelope until implemented.

## Commands

| Command | Status | Summary |
|---------|--------|---------|
| `kode init` | ✅ implemented | Recognize the Gradle project and generate `.kode.json` |
| `kode errors <file>` | 🚧 stub | Errors/warnings + surrounding snippets (LSP) |
| `kode refs <target>` | 🚧 stub | References to a class/function (LSP) |
| `kode test <target>` | 🚧 stub | Related test classes/functions (Gradle) |
| `kode tree` | 🚧 stub | Whole-project file tree (file system) |
| `kode symbols <file>` | 🚧 stub | Classes/functions/properties (LSP) |

All commands output JSON only: results to **stdout**, error envelopes to
**stderr**, with machine-readable exit codes (design ch. 07).

## Build & run

Requires JDK 21+.

```bash
./gradlew build            # compile + detekt + unit tests
./gradlew detekt           # static analysis (detekt, config in ./detekt.yml)
./gradlew test             # unit tests
./gradlew koverHtmlReport  # coverage report (build/reports/kover/)

# Run the CLI from the JVM:
./gradlew :app:installDist
./app/build/install/kode/bin/kode --help
./app/build/install/kode/bin/kode init

# Build a single native binary (requires a GraalVM toolchain):
./gradlew :app:nativeCompile
./app/build/native/nativeCompile/kode --help
```

## Project layout

Multi-module Gradle build aligned with Clean Architecture; the dependency rule is
enforced at compile time by module boundaries (design ch. 01 / 10):

```
:domain       entities / value objects / ports (no framework deps)
:application  use cases (depends on :domain)
:adapter      Clikt CLI, JSON presenter, .kode.json repo, file system (driven)
:app          Composition Root (Main.kt) + GraalVM Native Image build
```

## `.kode.json`

Generated by `kode init` and **recommended to add to `.gitignore`** (already
ignored here): it holds environment-dependent absolute paths and is intended for
a personal dev environment, not for team sharing.
